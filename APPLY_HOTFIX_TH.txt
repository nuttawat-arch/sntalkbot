SNTalkBot 2026.08.23-r7.4.3 Linux TeamTalk text hotfix

วิธีใช้กับ repo เดิมบน Windows:
1. แตก ZIP นี้ทับโฟลเดอร์ D:\SNTalkBot-Complete-Package\sntalkbot โดยคง path เดิม
2. จาก SNTalkBot-Release-Automation ให้รัน publish_all.ps1 ตามคำสั่งเดิม โดยอย่าใช้ -SkipDocker
3. หลัง publish สำเร็จ บน Linux รัน: sudo ttuhelper update
4. ตรวจ: sudo ttuhelper logs Multipurpose
5. ทดลองส่ง h ทั้ง Private และ Channel; /h ยังคงรองรับเพื่อ compatibility

Hotfix นี้แก้ TypeError: normalize() argument 2 must be str, not bytes
และเพิ่ม validator จำลอง TeamTalkPy Linux bytes/str เพื่อกัน regression
