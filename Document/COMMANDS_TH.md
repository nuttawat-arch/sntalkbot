# รายการคำสั่ง SN TalkBot

หมายเหตุเกี่ยวกับโหมดบอต:
- ถ้า `[features] player_enabled = False` คำสั่งเล่นเพลงจะไม่ถูกลงทะเบียน
- ถ้า `[features] server_management_enabled = False` คำสั่งจัดการเซิร์ฟเวอร์จะไม่ถูกลงทะเบียน
- `help` ภายในบอตจะแสดงเฉพาะคำสั่งที่เปิดใช้งานจริงใน instance นั้น


> วิธีใช้: ทั้งข้อความส่วนตัวและ Channel/Broadcast พิมพ์คำสั่งตรง ๆ โดยไม่ต้องใส่ `/` เช่น `h`, `p เพลง`, `ap on`, `wb off` ได้เหมือนกันทั้งหมด เครื่องหมาย `/` ยังรับได้เพื่อความเข้ากันได้กับของเก่าแต่ไม่จำเป็น ผู้ดูแลใช้ `ci off` เพื่อปิดการตอบสนองปกติต่อ Channel และ `ci on` เพื่อเปิดกลับ; moderation ที่เปิดด้วย `filter on` ยังตรวจข้อความที่บอตได้รับอยู่

ไฟล์นี้ตรงกับคำสั่งที่ลงทะเบียนจริงในโปรเจกต์และไม่มีชื่อคำสั่งซ้ำกัน `h` ใช้ได้ทั้ง Private และ Channel เมื่อ Channel Input เปิดอยู่ โดยบอตจะส่งหนึ่งบรรทัดด้านล่างเป็นหนึ่งข้อความแยกกัน

> หากส่งข้อความ Private ที่ไม่ตรงกับคำสั่งหรือ workflow ที่เปิดใช้งาน บอตจะตอบกลับว่าไม่รู้จัก/คำสั่งไม่ถูกต้อง และแนะนำให้พิมพ์ `h` เพื่อดูวิธีใช้ โดยจะไม่ตอบข้อความสนทนาธรรมดาใน Channel หรือ TeamTalk CUSTOM event เช่นสถานะกำลังพิมพ์

> การแยกประเภทเป็นข้อบังคับ: **Player Bot** ลงทะเบียนเฉพาะ Common + Player, **Server Manager Bot** ลงทะเบียนเฉพาะ Common + Manager, และ **Full Bot** เท่านั้นที่รวมทั้งสองฝ่าย คำสั่งย่อแยกตาม role เช่น `sd/sc/vt` อยู่ Common, `gl/c/sb/sf` อยู่ Player/Full และ `j` อยู่ Manager/Full โดยหนึ่งคำสั่งหลักมีคำสั่งย่อได้ไม่เกินหนึ่งตัว


## คำสั่งแยกตามหมวด

### ทั่วไปและข้อมูล

about : แสดงเวอร์ชัน ประเภทบอต สภาพแวดล้อม ข้อมูลติดต่อ และวิธีใช้ dr สำหรับแจ้งบั๊ก/ขอฟีเจอร์ คำสั่งย่อ: a
admins : ดูรายชื่อผู้ดูแลที่ออนไลน์อยู่ คำสั่งย่อ: ad
dr <message> : แจ้งบั๊ก รายงานปัญหา ขอฟีเจอร์เพิ่มเติม หรือเสนอแนะฟีเจอร์โดยตรงถึงผู้พัฒนา SNTalkBot
gcid [channel path] : แสดง Channel ID ของ TeamTalk สำหรับห้องปัจจุบันหรือพาธห้องที่ระบุ คำสั่งย่อ: cid
help [command] : แสดงรายการคำสั่ง โดยส่งหนึ่งคำสั่งต่อหนึ่งข้อความ TeamTalk ใช้: help หรือ help คำสั่ง คำสั่งย่อ: h
myinfo : แสดงข้อมูลบัญชี/เซสชัน TeamTalk ของคุณ คำสั่งย่อ: mi
report <message> : ส่งคำขอความช่วยเหลือหรือรายงานปัญหาไปยังผู้ดูแลที่ออนไลน์ คำสั่งย่อ: rep
search : ค้นหา Wikipedia และรับบทสรุป วิธีใช้: search <คำค้นหา> คำสั่งย่อ: sr
status : แสดงแดชบอร์ดสถานะตามประเภทบอตในคำสั่งเดียว: จำนวนผู้ใช้/กิจกรรม TeamTalk; Player แสดงเพลง คิว M1-M3 Autoplay และแหล่ง Cookies; ผู้ดูแล Manager/Full เห็น filter/ci/ic/lock/welcome เพิ่มเติม
weather : รับสภาพอากาศปัจจุบันสำหรับตำแหน่งของคุณหรือผู้ใช้ที่ระบุ วิธีใช้: weather [ชื่อเล่น (ไม่บังคับ)] คำสั่งย่อ: w

### เครื่องเล่นเพลง

+ : เดินหน้า 10 วินาที คำสั่งย่อ: sf
, [queue_position] : โหมดปกติใช้ `,` เพื่อเลื่อนไปผลค้นหาก่อนหน้า; Queue Mode ใช้ `,` กับรายการค้นหาล่าสุด หรือระบุคิว เช่น `, 34` เพื่อเปลี่ยนผลค้นหาของคิว 34 โดยไม่กระทบคิวค้นหาของคนอื่น
- : ย้อนกลับ 10 วินาที คำสั่งย่อ: sb
. [queue_position] : โหมดปกติใช้ `.` เพื่อเลื่อนไปผลค้นหาถัดไป; Queue Mode ใช้ `.` กับรายการค้นหาล่าสุด หรือระบุคิว เช่น `. 34` เพื่อเปลี่ยนผลค้นหาของคิว 34 โดยไม่กระทบคิวค้นหาของคนอื่น
3d on|off : เปิดหรือปิดฟิลเตอร์ขยายมิติสเตอริโอ/3D ชุดที่ 1
3d2 on|off : เปิดหรือปิดฟิลเตอร์ Extra Stereo เพิ่มมิติสเตอริโอชุดที่ 2
autoplay on|off : โหมดปกติให้เล่นเพลง Related Radio ต่ออัตโนมัติ; Playlist/Channel/Favorites ที่เปิดโดยตรงยังเล่นตามลำดับเดิม คำสั่งย่อ: ap
b : โหมดคิว ย้อนกลับเพลงที่เพิ่งเล่นจากประวัติคิว; โหมดปกติ ย้อนกลับในประวัติ Related Radio
bass on|off : เปิดหรือปิดการเพิ่มเสียงเบสสำหรับการเล่นเพลง
channel : ขณะเล่นวิดีโอ ให้โหลดช่องของวิดีโอปัจจุบันและเล่นวิดีโอแรกของช่อง คำสั่งย่อ: ch
d : แสดงเวลาทั้งหมด เวลาที่เล่นไป และเวลาที่เหลือของเพลงปัจจุบัน
dl <link> : ดาวน์โหลดเสียงด้วย yt-dlp แล้วอัปโหลดไปยังห้อง TeamTalk ปัจจุบัน
f : เปิดหรือปิดเอฟเฟกต์เฟดของเครื่องเล่น
hide : เปิดหรือปิดการซ่อนชื่อเพลงที่กำลังเล่นจากสถานะของบอท
l : ดู URL ของเพลงที่กำลังเล่น คำสั่งย่อ: gl
m : แสดงโหมด TT Player ที่ใช้อยู่ในขณะนี้
m1 : ตั้งโหมด M1 Single: หยุดหลังรายการปัจจุบันเมื่อไม่ได้เล่นจากคิว
m2 : ตั้งโหมด M2 Auto/Next: เล่นรายการถัดไปโดยอัตโนมัติ
m3 : ตั้งโหมด M3 Repeat: เล่นเพลงปัจจุบันซ้ำเมื่อไม่ได้เล่นจากคิว
n : โหมดคิว เล่นรายการถัดไปในคิว; โหมดปกติ เล่นเพลง Related Radio ถัดไปที่ใกล้เคียงจาก YouTube/YouTube Music
p <query> : ค้นหาและเล่นหรือเพิ่มสื่อจาก YouTube เข้าคิว
pg : แสดงข้อมูลและความคืบหน้าของเพลงปัจจุบัน
pm <query> : ค้นหาและเล่นหรือเพิ่มเพลงจาก YouTube Music เข้าคิว
pp <playlist_link> : ต่อ YouTube/YouTube Music playlist ชุดที่ 2, 3, ... โดยไม่หยุดเพลงปัจจุบัน; Queue Mode จะเพิ่มทั้ง playlist ต่อท้าย FIFO
r : แสดงเพลงที่เล่นล่าสุด
s : หยุดการเล่นเท่านั้น โดยเก็บคิว เพลย์ลิสต์ และรายการปัจจุบันไว้; ใช้ p เปล่าเพื่อเริ่มรายการเดิมใหม่จากต้น และใช้ cq เมื่อต้องการล้างคิว
select <index> : เล่นรายการลำดับที่ระบุจาก Queue หรือ playlist/session เช่น c 10; Queue จะข้ามข้อก่อนหน้าและเล่นต่อข้อ 11 ส่วนผลค้นหาใช้ . และ , คำสั่งย่อ: c
sp <speed> : ตั้งค่าความเร็วในการเล่นเพลง
t <time> : เลื่อนไปยังเวลาที่ระบุ เช่น 1:30
u <link> : เล่นหรือเพิ่มสื่อจาก URL เข้าคิว
v <volume> : ตั้งระดับเสียงเครื่องเล่นได้ไม่เกินค่าสูงสุดที่กำหนดไว้
x : พักหรือเล่นต่อ

shuffle : สุ่มเฉพาะเพลงในคิวที่ยังไม่ได้เล่น คำสั่งย่อ: sh

### เสียงพูดและ TTS

get_voices langcode : แสดงรายการเสียงหรือภาษาที่เลือกใช้ได้ตามโหมด TTS คำสั่งย่อ: gv
ld : เปิดหรือปิดการตรวจจับภาษา
pitch value : ตั้ง Pitch ของเสียง (เฉพาะโหมด Microsoft) ค่า -100 ถึง 100
ptts [on|off|status] : สำหรับผู้ดูแล: เปิด/ปิดหรือดูสถานะ TTS ประกาศเพลงและคิวของ Player; ใช้ tracks หรือ queue เพื่อแยกควบคุมได้
pttsmode microsoft|google : สำหรับผู้ดูแล: เลือกเสียง Microsoft หรือ Google สำหรับเสียงประกาศ Player คำสั่งย่อ: ptm
pttsrate <-100..100> : สำหรับผู้ดูแล: ตั้งอัตราความเร็วเสียงประกาศ Player เมื่อใช้ Microsoft คำสั่งย่อ: ptr
pttsspeed <0.25..4.0> : สำหรับผู้ดูแล: ตั้งความเร็วเสียงประกาศ Player ในโหมด Google คำสั่งย่อ: pts
pvoice <voice_or_language> : สำหรับผู้ดูแล: เลือกเสียงหรือภาษาของเสียงประกาศ Player คำสั่งย่อ: pvo
pvoices [langcode] : แสดงรายการเสียงหรือภาษาที่เลือกใช้ได้สำหรับ Player คำสั่งย่อ: pvl
rate value : ตั้งอัตราความเร็วเสียง (เฉพาะโหมด Microsoft) ค่า -100 ถึง 100
say : ให้บอทพูดข้อความที่กำหนด วิธีใช้: say <ข้อความ>
speed value : ตั้งความเร็วเสียง (เฉพาะโหมด Google TTS) ค่า 0.25 ถึง 4.0
st : สำหรับผู้ดูแลเท่านั้น: หยุดเสียงพูดที่กำลังเล่น
tts on|off : สำหรับผู้ดูแลเท่านั้น: เปิดหรือปิด TTS สำหรับทุกคน
ttsmode microsoft|google : เลือกเสียง TTS ระหว่าง Microsoft หรือ Google คำสั่งย่อ: tm
voice voiceOrLanguage : เลือกเสียงหรือภาษาที่ใช้กับ TTS คำสั่งย่อ: vc
volume value : ตั้งระดับเสียงพูด (เฉพาะโหมด Microsoft) ค่า 0.1 ถึง 1.0

### การแปลภาษา

tr : เปิดหรือปิดการแปลข้อความในห้องอัตโนมัติ วิธีใช้: tr <source_lang> <target_lang>

### ผู้ดูแลและการกลั่นกรอง

blockcmd [+|-]<command> : สำหรับผู้ดูแลเท่านั้น: บล็อกหรือยกเลิกการบล็อกคำสั่งสำหรับผู้ใช้ทั่วไป หากไม่ระบุคำสั่งจะแสดงรายการคำสั่งที่ถูกบล็อก คำสั่งย่อ: bc
bm message : สำหรับผู้ดูแลเท่านั้น: ส่งข้อความประกาศไปยังเซิร์ฟเวอร์
cg mode : สำหรับผู้ดูแลเท่านั้น: เปลี่ยนเพศของบอท โหมดที่ใช้ได้: m สำหรับชาย, f สำหรับหญิง, n สำหรับเพศกลาง

### ระบบและการดูแลบอต

clearlog : เฉพาะผู้ดูแล: ล้างไฟล์ข้อผิดพลาด/บันทึกของบอท คำสั่งย่อ: cl

exec : สำหรับผู้ดูแลเท่านั้น. รันคำสั่งบนเซิร์ฟเวอร์ผ่าน SSH (ต้องได้รับอนุญาต) วิธีใช้: exec [คำสั่ง]
language <code> : สำหรับผู้ดูแลเท่านั้น: บันทึกรหัสภาษาของบอต แล้วรีสตาร์ตบอตเพื่อโหลดทุกโมดูลด้วยภาษาใหม่ คำสั่งย่อ: lg
reboot : สำหรับผู้ดูแลเท่านั้น. รีบูตเซิร์ฟเวอร์ (ต้องได้รับอนุญาต) คำสั่งย่อ: rbt
restart : เฉพาะผู้ดูแล: รีสตาร์ตบอทผ่านลูปตัวเรียกหลักโดยไม่ต้องเปิดโปรแกรมใหม่ด้วยตนเอง คำสั่งย่อ: rs
save : สำหรับผู้ดูแลเท่านั้น: บันทึกการตั้งค่าในกรณีที่คุณเปลี่ยนชื่อบอทและต้องการบันทึก คำสั่งย่อ: sc
shutdown : เฉพาะผู้ดูแล: ปิดบอทอย่างถูกต้องและปลอดภัย คำสั่งย่อ: sd
