# Playlist / Web Controls — 26 ตุลาคม 2569 (Source DEV)

## คำสั่ง TeamTalk สำหรับ Player และ Full

- `pp <ลิงก์ Playlist>` — เพิ่มเพลงใน Playlist ต่อท้ายคิวหรือรายการเล่นตามพฤติกรรมเดิม ไม่ข้ามเพลงที่กำลังเล่น
- `pp <ชื่อ Playlist>` — ค้นหา Playlist แล้วส่งผลลัพธ์เป็นหมายเลขให้ผู้ที่ค้นหา
- `pps <หมายเลข>` — เลือกผลจากการค้นหาล่าสุดของบัญชีนั้นภายใน 180 วินาทีแล้วเพิ่มท้ายคิว

คำสั่งไม่บังคับเครื่องหมาย `/` นำหน้า แต่สามารถใช้ `/pp` และ `/pps` ได้ตามระบบเดิม การค้นหาไม่แก้ไขคิวเองจนกว่าจะเลือกผลลัพธ์ ลิงก์ Youtube/YouTube Music playlist แบบเดิมยังใช้ได้

## Web Manager

1. เลือก instance ที่เป็น Player หรือ Full แล้วเข้า **ควบคุมบอต** → ส่วน Playlist
2. พิมพ์ชื่อ Playlist แล้วกด **ค้นหา Playlist** เมื่อได้ผล ให้กด **เพิ่มท้ายคิว** ของรายการที่ต้องการ
3. ถ้ามีลิงก์อยู่แล้ว ให้ใช้ฟอร์ม **เพิ่ม Playlist จากลิงก์** ได้เลย
4. มีฟอร์มตั้งค่าเสียงพูดประกาศเพลง/คิวตามสิทธิ์ Player; ไม่มีปุ่มเลื่อนเพลงในคิวขึ้นลงหรือแทรกคิว

เว็บค้นหาผ่านบอตจริงและเก็บผลชั่วคราวพร้อม token เฉพาะการค้นหา การส่ง token ปลอม/หมดอายุไม่สามารถอ้างผลลัพธ์เก่ามาเพิ่มคิวได้

## สิทธิ์ของแต่ละบทบาท

| บทบาท instance | หน้าเว็บที่เห็น |
| --- | --- |
| Player | เพลง / คิว / Playlist / เสียงประกาศ Player |
| Manager | ประกาศ / Moderation / Jail / ตั้งค่า Server ที่ได้รับอนุญาต |
| Full | ทั้ง Player และ Manager ในหน้าเดียว แยกหัวข้อ |

การสั่งงาน Manager ที่กระทบ TeamTalk Server ส่วนกลางต้องเป็น **Web Super Admin** และบอตต้องเชื่อมด้วยบัญชี TeamTalk Administrator ตามการตรวจฝั่งเซิร์ฟเวอร์ ไม่ได้ขึ้นกับการซ่อนปุ่มเพียงอย่างเดียว

## ข้อจำกัดและสิ่งที่ต้องทดสอบ

- คุณภาพ/จำนวนผลค้นหา Playlist ขึ้นกับ YouTube และ yt-dlp รวมทั้ง network/cookie; ตัวค้นหามี HTML fallback เฉพาะเมื่อ yt-dlp ไม่ได้ผล
- Offline tests ไม่ยืนยันว่าได้สิทธิ์ BearWare TeamTalk จริง, YouTube ยอมรับ cookie, หรือ NVDA ใช้งานได้ครบทุกรูปแบบ
- ความสามารถ TeamTalk SDK บางส่วนยังไม่ได้พัฒนาครบ เช่น file transfer/ACL และการจัดการบัญชีขั้นสูง; ดู `TEAMTALK_SERVER_ADMIN_TH.md`
- ไม่มีเมนู PowerShell หรือ arbitrary command input ใน Web Manager และไม่เพิ่มฟีเจอร์สลับคิวขึ้นลงตามความต้องการ
