# Notices and upstream attribution

SNTalkBot is a substantially extended TeamTalk bot assembled from multiple upstream codebases and original integration work.

## TeamTalk admin utilities / TTUtilities upstream

The original TeamTalk admin utilities project was developed by the BlindMasters team and distributed under the GNU General Public License version 2 (GPL-2.0). SNTalkBot retains GPL-2.0 as the license for the combined main project. The full GPL-2.0 text is in `LICENSE`.

The current project name, SNTalkBot, is intentionally different from the upstream TTUtilities name so that users do not confuse this modified project with the original project.
